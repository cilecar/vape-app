# Жижи — трекер жидкостей и стиков

Android-приложение (React + Vite + Capacitor) для личного учёта:

- **Каталог жиж и стиков** — фото, оценки по критериям, история цен, сравнение, карточка «поделиться».
- **AI-поиск** — заполняет бренд, название и описание вкуса через Gemini. Включается и выключается в настройках, там же вписывается ключ.
- **Счётчик стиков** — пачки, «+1 стик», ввод остатка, график за 14 дней, расходы за 30 дней.
- **Вечернее напоминание** — можно ответить остатком прямо из уведомления.
- **Настройки** — тёмная/светлая тема, русский/английский, валюта (₽ / дин), ИИ-распознавание с ключом Gemini, бэкап в файл и восстановление.

## Запуск

```bash
npm install
npm run dev                  # в браузере
```

## Сборка под Android

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Ключ Gemini в сборку не встраивается — он вписывается в настройках приложения и хранится на телефоне.
